# Ljuskalkylatorn

En webbaserad applikation för att skapa, beräkna och hantera recept för egentillverkade ljus.

## Teknikstack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- React Router

## Kom igång

### Installera beroenden

npm install

### Starta utvecklingsservern

npm run dev

### Bygg projektet

npm run build

### Kontrollera kod med Oxlint

npm run lint

### Generera Supabase-typer

npm run types
